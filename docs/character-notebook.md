# 角色、感知与服务器笔记

安装插件后，从侧栏 Minecraft 进入配置。已有快捷配置的角色可在游戏页点“角色与笔记”；看笔记不需要下线，修改连接、人设和感知前点“停止并修改配置”。本页只操作当前 profile 的角色，不修改 DSH 全局配置。

## 配置入口

- **连接**：服务器、账号、可选首次任务。版本默认 auto；普通服务器不用密码，不自动注册。
- **感知与工具**：矿物透视查询默认关，依靠实际发现和笔记。开启仅扩展方块查询到 32 格内已经接收的遮挡矿物，不改变画面或身体动作检查。可关闭网页画面、选择简洁或完整工具目录。
- **角色与皮肤**：复用鸣人、桐人、爱德华三份档案，也可自定义名称、性格、背景和初始记忆。预设的故事不是服务器事实。上传 64×64 / 64×32 PNG、选择宽臂或细臂；仅用于本人本地网页预览，服务器与其他玩家所见由服务器或正版皮肤决定。关闭本地预览不删除保存的图片。
- **服务器笔记**：新建、搜索、修改和归档矿点、兴趣点、人物、任务线索、方法、经验或普通记录。按维度查询；正文写清坐标、时间、来源、采集后变化和未知项。界面修改记为主人报告，Agent 的发现经 `mc_memory` 记录，两者共用核心笔记与版本检查。归档保留历史，不删除文件。
- **DSH 插件**：选择当前 DSH 已声明的 Agent 能力预设，可携带记忆、搜索等插件。它通过官方 `agentPresets.mount` 挂载，不另写插件加载器；插件的提示、上下文和作用域工具会保留。人格使用官方 persona 段，已提供的压缩服务不再重复加载。更换已有会话的能力时，需明确勾选新建会话；原会话、同一角色和游戏笔记保留，新会话不自动重放旧任务。

“仅保存配置”不连接游戏、不创建 Agent 会话、不解析模型元数据，也不调用模型。保存后即能使用离线笔记。“保存并连接游戏”才连接身体；留空首次任务不会主动创建游戏目标。

默认只开放 Minecraft 工具。主动选择 DSH 能力预设后沿用该预设的工具权限与继承规则，包括它允许的宿主工具；插件不再额外施加空白名单，以免过滤掉记忆等预设工具。请只选择自己信任且已配置的能力预设。

## 检索与隔离

默认使用轻量的本地 CPU 词元向量 + 关键词混合检索，不需要 GPU、API Key 或模型下载。它计算词元相似度，不是神经语义模型。也可选择仅关键词，或填写自己的 embeddings 完整地址、模型与密钥环境变量名；仅显式索引/查询相关游戏笔记时访问该服务。外部服务故障时保留本地记录并明确报告降级。外部 DSH 记忆插件与核心游戏笔记可以并存，插件自行管理其存储与调用。

角色数据按服务器地址、认证方式和游戏账号隔离；核心笔记再区分稳定 Agent 标识和维度。修改显示名字不会换一本笔记。不同账号不自动共享；地址别名、世界重置和跨服不自动合并。要迁移请保留完整本地数据目录，不仅复制向量索引。

Agent 已有 `mc_memory` 的 help/search/get/remember/revise/archive 接口。可先读 `{"action":"help","topic":"remember"}`，将实际发现保存为 resource/place 等，再在重访前按需查询并复核。旧笔记不直接注入为当前事实；不会后台读取全部区块给矿点“补真值”。

## 本地存放与回滚

快捷配置在当前 DSH profile 的 `minecraft-agent/quick-setup.json`。每个账号目录保存 `character.json`、生成的 `persona.md`、原会话标识及 `body/minecraft-memory/`。私有密码文件与笔记不进入发布包或公开指标。修改配置不清空目标、会话日志或笔记；选择预设也不会改游戏账号。

回滚代码时停止此角色，恢复先前的插件和核心包，保留完整私有目录；v2 快捷配置不能交给只理解 v1 的旧入口自动启动，应使用备份的旧配置或手动核对后重新配置。不要回写旧笔记覆盖新发现。此功能的源码、候选包、npm 发布与生产加载分别记录。
