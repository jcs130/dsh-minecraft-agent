# 截图来源

根目录 `screenshots.json` 是社区市场的截图清单，实时观战排在最前。图片均为实际浏览器截屏，未生成、拼接或修改游戏内容。

| 文件 | 来源与边界 |
| --- | --- |
| `live-spectator-20261026.jpg` | 2026-10-26 共享 Agent MC World 核心的现有线上观战，Minecraft Java 1.21.1，3D 简洁视图。 |
| `live-spectator-hud-20261026.jpg` | 同一次线上观战，保留地图、技能、动作及状态信息。服务器自定义技能、地下城与角色外观不是通用服务器的默认能力。 |
| `game-and-reasoning.png` | rc.15 的官方 DSH Web 集成验收；同一连接的游戏画面和 DSH 原生会话并排。模型文字是页面中已标注的离线 UI 测试数据。 |
| `quick-setup.png` | DSH Web 首次接入表单的离线 UI 验收。 |
| `rc19-character-settings.png` | rc.19 DSH Web 角色设置页验收；示例人格是演示配置。 |
| `rc19-server-notebook.png` | rc.19 DSH Web 服务器笔记页验收；笔记和本机账号是隔离测试数据。 |

2026-10-26 截图仅访问已有观战网页，没有连接新的游戏账号、接管角色或额外调用模型；简洁显示选项在截图后恢复，截图标签页已关闭。角色在拍摄期间由原有 Agent 自行行动。线上截图展示共享核心的功能，不能用来证明当前 npm 包的 Desktop 原生窗口已完成验收。

版本、默认安装与运行时加载的验收见 [npm 分发记录](../npm-publish-rc22.json)，实际游戏行为、宿主 Web 集成和 Desktop 原生画面分别说明。
