# rc.18 候选：原版连接与网页画面

候选使用 `agent-mc-world@0.5.7-rc.85`，沿用 `agent-mc-qiandengji@0.5.0-rc.22` 的共享核心 peer 契约。当前仍未发布 npm，市场继续指向已公开的 rc.17。源码合并、候选安装、公开发布和现役部署分别记录。

## 修复

- 新的首次配置与 dry-run 默认 `auto`，让 Mineflayer 协商实际支持的协议；显式版本原样保留。1.21.1 是维护基线，不再作为网页画面的版本白名单。
- 共享核心按实际协商版本选择精确资源和注册表。新增 Mojang 1.21.11 原模型、纹理、物品定义、图集与字库，补齐新图集的命名空间、装备贴图路径及浏览器字库加载。缺失资源不借用 1.21.1 或 1.21.4。
- 游戏连接与画面启动分别显示。已连接但画面资源缺失、校验失败或端口占用时提供具体状态；重连换代和断开时不保留旧画面。
- DSH 不提供未配置的观察者/玩家原生客户端启动按钮；服务端动作接口也拒绝这些入口。Agent 本身的连接与微软授权、同连接网页画面、3D 观战、原会话、决策与行动、指标和实验室保留。
- 普通聊天默认公屏，可直接在文字中点名。移除公屏限额用完后建议改用 `/msg` 的提示。只有明确要求私聊且已确认服务器支持时才使用相应命令；不将失败的私聊重发公屏，不用私聊绕过限额。

## 已有配置

如果旧配置保存了 `1.21.1`，更新代码不会擅自覆盖它。进入 Minecraft 的“停止并配置”，展开可选设置，将协议改为 `auto` 或实际支持的服务器版本，再保存连接。普通服务器留空 `/login` 密码；不自动注册。

## 验证范围

使用隔离的官方 Mojang Java 1.21.11 服务器，通过首次配置表单以离线身份、无密码、`auto` 连接，验证实际协议 774、世界就绪及 DSH 内嵌 WebGL 地形。确认 Agent 账号是唯一显示的连接入口，断开后旧画面消失。全过程没有外部模型调用，没有现役账号、Cortico 或服务器重载。

共享渲染器完整回归包含原 1.20.6/1.21.1 与新增 1.21.11 资源验证；浏览器字库测试使用实际原 PNG/Unihex 与 node-canvas，核验拉丁、中文与指针字形。核心全量 2060 项通过、1 项既有可选测试跳过；DSH 0.2.1-rc.2 / rc.3 各 125 项通过，外部 Harness² worker 测试未配置而跳过。测试期间的旧失败日志保留，最终结果独立记录。

1.21.11 音频、地图/粒子扩展、新实体模型、完整 Java 画面等价，以及真实 Desktop 原生窗口不在本轮验收内。协议、游戏目标成功、全版本支持不能由一张画面或工具完成率推出。具体包哈希与最终截图见 `viewer-verification-20261025.json`。
