# rc.24：核心 rc.99 与宿主查询契约

保留首次配置、第一／第三／3D 观战、DSH 原生推理与工具会话、实验室、角色及服务器笔记、可选 MineDojo 本地索引。缺少精确材质仍显示兼容画面；普通服务器无需密码，协议默认 auto。
