# 网页资源与聊天

同内容的跨版本图片按 SHA-256 共用一份文件，各版本资源路径保留；有差异的纹理、模型及方块编号注册表分别保存。其他玩家默认从同一游戏连接收到的原版 textures 属性同步皮肤和宽／细臂模型，资料迟到也会刷新。本人上传的本地皮肤优先；离线服未发送皮肤属性时保持默认外观，不凭名字查询。角色面板可关闭“同步服务端玩家皮肤”。

画面内「画质与特效」可分别开关粒子与受击特效、声音波纹／光环／技能提示、雨雪及动态人物阴影。关闭会释放对应已有特效并停止生成，无需重连；音频、生命值及状态图标独立。设置保存在当前浏览器来源，换来源或浏览器需重设。OBS 沿用同来源普通画面保存的选择。

连接协议使用 Mineflayer 的实际协商结果，预装资源版本不是允许连接的版本清单。插件的新候选内置 Java 1.21.5 的原版画面资源；缺少可选物品图标、文字展示字库或音效时，只报告对应功能不可用，不以此挡住地形画面。

其他实际支持的 Java 版本可由 Agent 按需补全资源：

1. 调用 `mc_connection {"action":"viewer-status"}`，读取实际版本、资源根目录及共享修复指南。
2. 需要终端和文件操作时，在 DSH 中选择已配置且可信的能力预设；Minecraft 工具本身不授予任意 Shell 权限。按[共享资源准备说明](https://github.com/jcs130/mc-visual-console/blob/main/docs/vanilla-viewer-resources.md)，在独立检出中准备构建依赖，运行 `tools/prepare-vanilla-viewer.mjs`，将 `--output` 指向返回的资源根目录。脚本下载并校验官方素材，支持该构建依赖实际拥有注册表的版本，不把其他版本的方块编号套过来。
3. 成功后调用 `mc_connection {"action":"viewer-retry"}`，或在网页点击“资源已补全，重试画面”。只重试网页服务，不重新登录游戏，也不重放任务。核对状态变为 ready 和实际可见场景。

源码技能 `minecraft-agent/references/viewer-resources.md` 也保留这份按需修复入口。准备过程不调用 LLM、不修改服务器；缺少 Python/Pillow、终端权限或写权限时，明确指出缺项，不修改 DSH 的可执行文件或凭据。新版代码、源码文档、npm 发布和已有实例加载分别核验，安装新包前请确认使用的是包含修复的版本。

公屏聊天默认会送给 Agent 判断，不要求点名；自发消息、系统提示和归档旧消息不因此唤醒。Agent 根据相关性选择是否回应，可在普通文本中写 `@玩家名`。配置页的“感知与工具”可关闭普通公屏唤醒，仍接收私聊、点名和危险事件。高级配置 `wake.on` 继续生效，`wake.publicChat` 可显式开关普通公屏。

默认没有整个运行期间四句的公屏总上限，保留五秒发言间隔；高级配置仍可显式设置 `chat.maxPublicLines`（0 表示不限制总句数）和 `chat.minIntervalMs`。这不等于每条消息必定触发回复。

普通交流优先公屏；明确选择私聊时优先用原版 `/tell 玩家名 内容`，不依赖服务器插件的 `/msg`。服务器可禁用命令或修改权限，按真实回执判断；失败或结果未知的私聊不自动重发公屏。选择公开交流时另写适合公开的 `@玩家名 内容`，保留原私聊的私密性。
