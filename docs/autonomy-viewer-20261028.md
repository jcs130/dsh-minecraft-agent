# 持续运行与观战修复

连接页默认开启「持续自主运行」。目标非空时保留同一会话和目标，按原生窗口持续规划、执行和验证；30 个模型步骤是安全让出点，40 轮是可延长的日志窗口，不再是整个目标的累计上限。旧的明确有限预算仍可选，目标留空只连接。

连续无进展先给模型证据和调整提示，再短暂休整后恢复；未知结果查询原任务，不重复提交。用户暂停、断开、完成整个目标、未知阻塞和持久化失败不被自动越过。模型、思考等级和工具动作语义保持由宿主及核心原接口决定。

共享可视化修复来自 `mc-visual-console` PR 9、10，最终源提交 `c0b9a7a6772c2f4de8c502a091af10f363bc427a`，通过核心 rc.115 冻结消费：

- 第一人称按实际镜头所在的区段裁剪；镜头区段为空或未建立连通图时保留已收到的洞壁，避免错误剔除形成蓝洞。
- 背包预览使用自己的矩阵和中立姿态，不受世界朝向、第一人称隐藏或其他世界变换覆盖；不修改实际角色。
- 原版 64×32 旧皮肤按原像素转换至现代 UV。现代铜甲等从同版本原资源的 equipment 路径接入，不以旧版本素材替代。
- 原自定义整身模型不再叠加经典护甲；保留原持物矩阵及模型恢复标记。

Java 1.21.1 为主验收版本，1.20.6、1.21.11、1.21.5 的网页与 mesher 均独立重建并记录原客户端指纹。1.21.11 部分可选粒子、照片和声音资源仍缺失，缺项如实提示，不阻止已有地形和装备显示。

本地核心候选还保留上游的换手与实际进食确认、明确取物数量，以及可达水岸选择、游泳朝向和寻路终态修复。最终验证固定在核心 `1e728bca`，不把之后的并发源码变化混入该候选证据。

验证包括空镜头区段的实际 WebGL 夹具和原版护甲预览、独立 SDK/MCP、官方 DSH 主进程与 Worker、原生目标日志回放及崩溃恢复。夹具不登录 Minecraft、不调用外部模型。没有用户原皮肤 PNG 或其原场景存档，不能据此声称像素完全一致，也不把离线累计轮次当长期实服收益。

最终核心完整回归 2443 项通过、1 项条件跳过；共享渲染/工具 1398 项通过、39 项条件跳过（根、宿主等其他套件另行通过）。官方 DSH 0.2.1-rc.2 与 rc.4 各 175 项通过、1 项可选跳过；独立安装包的 19 个运行文件、共享物理核心、38 个 MCP 工具及本地知识库查询通过。详见[机器可读记录](autonomy-viewer-20261028.json)。未公开核心仅在私有验收 workspace 使用本地覆盖，不带入正式插件依赖，也不把这种测试当默认公开 registry 安装验收。

源码合并、安装包发布、市场索引、现役加载分别记录。本次源码与隔离验证不会重启 Cortico、服务器或角色。升级前保留原会话、目标、记忆与账本；若需回滚，停在宿主空闲边界后在原 DSH 配置中重新安装 `@jcs130/dsh-minecraft-agent@0.3.0-rc.24`，无需删除会话或游戏密码。原生 Desktop 窗口和真实长期自主运行仍需单独验收。
