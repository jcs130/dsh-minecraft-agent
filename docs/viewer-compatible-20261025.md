# 没有预制材质也能使用兼容画面

插件 rc.22 使用核心 rc.89。连接原版服务器时，即使没有该版本的预制材质，也会自动选择已有兼容素材显示画面。浏览器及网格线程仍使用实际游戏版本的方块和物品编号；同名素材复用，缺失的新素材显示棋盘占位，不会隐藏整个场景。

默认流程是配置、连接、查看画面。普通用户不需要先安装 Python、下载客户端 JAR 或手动构建资源。旧缓存不完整时会尝试包内素材；图标、字体、绘画或声音暂缺只影响相应效果。游戏与画面状态分别显示，画面暂时不可用时仍可行动和聊天。

`mc_connection` 的 `viewer-status` 返回 `resources.mode`、实际版本和素材版本。兼容画面已经可用，不应被 Agent 当成必须优先修复的故障。需要精确新素材时，Agent 可按[可选增强说明](viewer-resources-chat.md)准备资源后调用 `viewer-retry`，只刷新画面，不退出游戏、不重放操作、不清除目标或记忆。独立的原生模组渲染仍保留严格的原始资源要求。

共享源码、核心构建、实际浏览器夹具及安装包消费验证分别记录；没有因此重启现役服务或调用游戏模型。npm 与 GitHub 发布状态见[分发记录](registry-release.md)。
